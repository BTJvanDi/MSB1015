In order to run the following code, some files are required from Kaggle. This dataset https://www.kaggle.com/datasets/rohanrao/formula-1-world-championship-1950-2020 contains all the data of the last 74 years of formula one data. Install the files and store them in a folder of choice. Unpack archive.zip in a folder and make 2 additional folders, interval and ML. Make a subfolder in ML called simply data.  
The data we will predict on in the end is from the 2025 season. This is not included in the kaggle dataset and was recreated by myself personally. It can be found under the name f12025 in the files. Put this dataset in the interval folder.
